### Your Oby's MCP server, by the spec

`rep.mjs mcp` (and `obysphere mcp`, which the Claude Code plugin runs) now follows the MCP specification more closely, checked against it on 2026-11-25. Everything 0.3.0 added stays as it was: the channel, `sphere_use`, notifications and the GitHub tools.

- **Version negotiation.** `initialize` answers with the version the app asked for only when `rep.mjs` speaks it (2024-11-05, 2025-03-26, 2025-06-18, 2025-11-25), and 2025-11-25 otherwise. Before, it echoed any version back, even one it doesn't speak.
- **The 2026-07-28 protocol.** It has no handshake: each request names its version and the app's capabilities in `_meta`. `rep.mjs` answers `server/discover` (the versions it speaks, its capabilities, its instructions), puts `resultType` and its name (`serverInfo`) on every result, and puts caching hints on `server/discover` and the lists (`ttlMs` 0 and `cacheScope` private: they name you and your downloads folder). A version it doesn't speak gets `-32022` with the versions it does; a request without `clientCapabilities` gets `-32602`. That version has no `ping`, and the channel starts only with `initialize`, so such a request gets neither. Apps that start with `initialize` are served as before, and so is a request that names a handshake version.
- **Batches.** A JSON-RPC batch (2025-03-26) gets one array back once every request in it is answered. What isn't a request gets its error in the array, a batch of notifications gets nothing, and an empty batch gets one error.
- **Cancelling.** After `notifications/cancelled`, nothing more is sent for that request. A waiting `sphere_ask` or `sphere_use` stops at its next report of how it's going, whether or not the app asked for progress. A later request may use the same id at once.
- **A clean exit.** When stdin closes, `rep.mjs mcp` writes out what it has and exits with 0, even with an ask still waiting. It exits with 0 too when the app stops reading.
- **Stray lines.** A line that isn't a request (`null`, a number, a response) no longer makes it answer or crash. A request whose id is neither a string nor a number gets one `-32600`, and `params: null` counts as no params.
- **Tests.** `test/mcp-protocol.test.mjs`: an MCP session over stdio for every version against a test relay, version negotiation, batches, cancelling (also inside a batch), stdin closing, the app no longer reading, stray lines, and every tool's input schema checked strictly (an object at the root, every property typed and described, no array without items, no `$ref`, `anyOf` or type lists): in your own session, in an answering one, with GitHub on, and the plugin's `obysphere_setup`.
