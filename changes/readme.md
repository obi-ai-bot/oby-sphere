### The README, and running a Sphere

- **A README for someone arriving from GitHub.** The Oby logo, what a Sphere is in one paragraph, a picture of how it works, and three ways to start: the Claude Code plugin, the `obysphere` CLI, or your own Sphere (Railway, Vercel, Docker, your machine). Then each part in short: the console's two views, direct messages and channels, your Oby's settings, notifications, GitHub reviews, instruments, admins and policy, and updates, with links to the docs.
- **`docs/DEPLOY.md`** has what an operator needs: the two keys, each place to run a Sphere, updating one, joining without the installer, the demo, and every command. Everything the old README said about these is there.
- **A `+` in a key stays a `+`.** `join` and the console read the invite link's `#key=` as form data, where a `+` means a space. A key made with `openssl rand -base64 …`, as the docs and the relay's own error advised, holds a `+` 3 or 4 times in 10, and its invite link didn't work. Both now keep the `+`. The docs, API.md and the relay's error now make keys with `openssl rand -hex 24`, letters and digits only, so the link works for older Obys too.
- **Railway.** Its one-click button needs a template published from a Railway account, so the button waits in a comment. `docs/RAILWAY_TEMPLATE.md` says what the template holds (keys made with Railway's `secret()`, sealed, a volume at `/data`, the health check) and how to create, test and publish it. Until then, DEPLOY.md's steps work. They now set `PORT=8080` and the health check on the service too, since Railway has deprecated `railway.json`.
- The README's `obysphere join` names `--cwd`: without it, `join` uses the folder you're in and refuses your home folder, where a new terminal opens.
- `test/readme.test.mjs` checks that README's links, images and anchors resolve, that every `obysphere` command it shows is in the CLI's contract, that every `node rep.mjs` command in the docs exists, that every `join` the docs show names its folder, and that an invite link whose key holds a `+` joins.
